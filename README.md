<span style="color:#999999"> 定位：
<i style="color:#dddddd"> 唯物怀疑主义、科学怀疑论、元哲学与认识论

这个仓库实际上不止一本著作，实际上有三本：[视界唯物主义](视界唯物主义（唯物怀疑主义、元哲学与认识论）.md)、[意识的熵论](意识的熵论.md)、[怀疑论与唯物主义](怀疑论与唯物主义.md)

他们里面都是一些**哲学实验**，  
他们是对认识的定位，也是对其**彻底的怀疑**。

众所周知，_怀疑论_ 是哲学的 _王水_ ，  
从后苏格拉底时代到今天不知道已经酸解了多少牢不可破的主义，多少坚定地信念，以及  
多少被酸完了的可怜虫。

他是伴随着哲学的发展而发展的，是相伴相生的绑定产物——有人相信，就有人不相信。  
怀疑论是一直存在的，只要某主义有一个缺点，就会大量滋生。  
然后——如果不及时——补上它——实际上也补不上，那就会——轰然倒塌，轰！

然后出现了一批人，又给它重新建立起来。  
然后怀疑，又倒塌。  
然而在这个过程中，又将逐渐淬炼出与其相适应的主义。

唯物主义固然是世界上最先进的主义，但是这里的情况是怎么来的呢？  
事情说道，那年我猜想共产之后，以及超长历史跨度的问题。  
我思考着，似乎发现唯物主义似乎有点乏力。

各种事情，没有固定的约束了，唯物主义的一些旧方法不能放上去了，怀疑就产生了。  
我那时虽然不知道怀疑论，但是却是天天往里面跳，给自己泼王水，居然练出点抗性来？！  
这些文章就是分享这些东西的。

巧合的是，我不知道 _批判实在论_ ，但是我的理论与其异曲同工，极度相似，  
批判实在论的介绍可见 <http://philosophychina.cssn.cn/fzxk/kxjszx/201507/t20150713_2729064.shtml>

但是我看完他的简介，我又觉得我与他不同，  
我有更彻底的怀疑。

我在检索 _“怀疑论唯物主义”_ 的时候发现了 _批判实在论_ ，但随后，我没有把这个理论定位为 _批判实在论_ ，  
而是选择了 _“唯物怀疑主义”_。

这些理论都要面临一个极度扯淡的一个处境，**元理论必须解释自己**，  
这是因为“**元理论**”是从普通理论出来的，**它本身就是理论**，只不过是再抽象一级，再索求一级原因。  
因此自从他出生，就是有“**生成式**”的理解模式，而且他妈的还得**自举**，递归逻辑链，正常人受不了，没有这种思维模式你知道吗。  
然后那我只能搬出 _结构主义_ 对抗这种撒币极致的**递归自指**，而且有时候还要自反一下，服了。

还有很多很多的**认识的结构性矛盾**，都是表现成这种 **递归自指** 的，然后他们就变成各种各样的悖论。  
这样子直接整得我放弃原来那种理解模式，从“承诺”，到“描述”，到最终的“我拟合，罢了”。

就此，也就是说，这个理论是**用来对抗认识的结构性矛盾**的。

这些是我与许多兴趣的贡献者一起编写的，出于临时的哲学兴趣，搞出的思想实验。
