## 关于文献

我与 _吞金鲸（deepseek）_ 做过大量交流，文档前期是由我拟提纲他总结我提出的东西编写的。  
所以失真有点严重，某些地方意思突出的不够明显，甚至是不合原意，日后逐渐修改。

值得参考的手稿：

- [世界原型与观测论 2026-4-1 残稿](<old versions/世界原型与观测论 2026-4-1 残稿.md>)  
   这部分虽然是ai填了提纲，但是修改之后几乎是手写的，味道最足。

- [世界原型与抽象唯物主义 2026-4-2 草稿](<old versions/世界原型与抽象唯物主义 2026-4-2 草稿.md>)  
   和ds讨论之后，初步起形。

- [视界唯物主义（元哲学和认识论） 2026-4-4 稿](<old versions/视界唯物主义（元哲学和认识论） 2026-4-4 稿.md>)  
  略微系统，但是我不满意，ds有一些意思给我抹去了。

- [唯物主义与怀疑论 2026-5-29 稿](<old versions/唯物主义与怀疑论 2026-5-29 稿.md>)
  [视界唯物主义（唯物怀疑论、元哲学与一般认识论） 2026-5-28 稿](<old versions/视界唯物主义（唯物怀疑论、元哲学与一般认识论） 2026-5-28 稿>)
  原来第三稿之后我就立即想写第四稿的，但是那时候放弃了。  
  直到五月我又回来，用另一个切入点研究视界唯物主义，  
  但是发现深入研究我预先用以定位的唯物怀疑论却越来越需要深入理解，以确定我到底要研究什么，但是没有人提到过这个词。  
  于是我首先研究唯物主义与怀疑论的关系，我发现大有搞头，于是先研究一般的唯物怀疑论了。  
  确定好了基调，我又回去重新编辑了视界唯物主义。
